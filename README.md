Химический класс, I семестр 2026/27. Кабинет 40, 38 уроков в неделю.

| Файл | Что это |
|---|---|

| `out/v1-raspisanie-10L-SUNC-MGU.pdf` | первый вариант: A3, альбомный, 10 полос |

## Пересобрать

```bash
python3 книга.py      # книга А4
python3 build_v1.py   # первый вариант, A3
python3 build_web.py  # лендинг
```

## Откуда данные

`internat.msu.ru` → «Учащимся» → «Расписание уроков»:
файл `1-semestr-26-27-s-kabinetami_s-03-09.xlsx`, колонка **10-Л** (каб. 40).
Границы сдвоенных блоков сняты по рамкам ячеек и **сверены с картинкой**
`raspisanie-26-27-1-sem-2-scaled.jpg` с той же страницы. Звонки —
со страницы «Учебный отдел», единые для всех классов.

Расхождение источника оставлено как есть: полдник в нём начинается в 16:40,
за пять минут до конца 8-го урока. Об этом сказано на полосе «Звонки».

Химпрактикум в среду по сетке занимает 7-й и 8-й уроки и тянется дальше —
в исходнике его блок доходит до десятой позиции, для которой звонков нет.

## Направление

`ФИЛОСОФИЯ.md` — «Хронохром»: время откладывается в подлинной пропорции,
за каждым смыслом закреплён свой цвет. Высота полосы равна длительности,
провал в левой колонке блока — перемена внутри сдвоенного урока.

Знак класса — ароматическое кольцо: шесть рёбер шести цветов. Химия для
химического класса и одновременно шесть учебных дней. Эмблема СУНЦ
перерисована вектором с `logo.png` сайта, цвета сняты пипеткой.

## Грабли

- **Переменные шрифты** reportlab берёт в дефолтном начертании: Unbounded,
  Manrope и Onest пришлось нарезать на статические через `fontTools.instancer`.
- **Разрядку** нельзя ставить через `Tc` — она утекает в весь дальнейший поток.
  В `книга.py` каждый знак сдвигается руками (`разрядка`).
- **Ось Y в SVG** идёт вниз, а в reportlab вверх. В `svg_sunc` из-за этого
  третий (синий) куб сначала уезжал за нижний край viewBox: в вебе знак был из
  двух кубов, в книге — из трёх. Верхний ряд кубов сидит на `r`, а не на `2.5r`.
- **Структура сдвоенных уроков** в xlsx не задана объединением ячеек: слияния
  там только горизонтальные, для потоков между классами. Границы блока читаются
  по нижней рамке (`thin`) — по ней и разобрана колонка.
